Privacy Policy – Maylami Club: Billiards

Effective: 15 November 2026

This page explains what data the game Maylami Club: Billiards (Android, package com.maylamiclub.billiards) collects and what happens to it.

Controller: Martin Krajči, Slovakia
Contact: martinmellokrajci@gmail.com

In short

  • This version of the game has no accounts, no sign-in, no purchases and shows no ads.
  • Almost everything you enter stays on your phone only.
  • The only data leaving the phone are crash reports (can be turned off) and bug reports you send yourself.

Data stored only on your phone

This data is never sent anywhere:

  • the name (nickname) and avatar you choose;
  • your age group (under 13, 13–15, 16–17, 18+) – the year of birth is not stored;
  • statistics, match history, tutorial progress, unlocked characters, the game in progress;
  • game settings;
  • an anonymous player ID (a random string not linked to your identity);
  • a technical game log – the last ~2 MB, continuously overwritten.

You can delete everything in Settings › Account & data › Delete all data, or by uninstalling the game.

Crash reports (Firebase Crashlytics)

When the game crashes or a serious error occurs, a report is sent to Firebase Crashlytics, a Google service. It contains:

  • a technical description of the error (location in the code);
  • phone model, Android version, free memory and similar technical details;
  • game version and selected settings (e.g. language, graphics quality, game mode);
  • the anonymous player ID and a Firebase installation identifier;
  • the last lines of the game log.

It does not contain your name, avatar or age. It is used only to fix bugs (legitimate interest in a working game). Google keeps this data for about 90 days.
To turn off: Settings › Account & data › Send crash reports.
More: https://firebase.google.com/support/privacy

Bug reports you send yourself

In Settings › About › Report a bug you can send a description and the game log. The game never sends it on its own – it opens your phone's share menu and you choose where to send it (e.g. e-mail or Discord). The log contains technical data as above, not your name. You can leave the log out. Whatever you send via Discord or e-mail is also subject to those services' policies.

Other services

  • Rating the game: the rating window is shown by Google Play. The game cannot see whether or how you rated it.
  • Links in the game: on start, the game downloads a small file with links (Discord, e-mail, this page) from GitHub Pages. As with any website, the server sees your phone's IP address. No other data is sent.
  • Discord is a separate service; the game only opens an invite link.

Children

The game is suitable for all ages. It only asks for an age group (can be skipped) so that content can be set correctly in the future. No personal data is collected from children outside the phone.

Your rights

Under the GDPR you have the right to access, rectify and erase your data, to restrict processing and to object. Because most data stays on your phone, you manage it directly in the game. To have crash reports deleted, write to us with your player ID (Settings › Account & data). You can lodge a complaint with the Slovak Data Protection Office (https://dataprotection.gov.sk).

Changes

If we add new features (for example optional ads, online play or cloud backup), we will update this page beforehand and notify you in the game.
