# Maylami Club: Billiards – web

The small public web of the mobile game **Maylami Club: Billiards** (GitHub Pages).

- `privacy/` – Privacy Policy (English)
- `ochrana-sukromia/` – Ochrana súkromia (Slovak)
- `links.json` – the links the game downloads at start (Discord, bug report e-mail, privacy policy)

The pages are generated from the game's private repository. Do not edit the HTML here by hand.
When a link in `links.json` changes, raise its `contentVersion` – the game takes only a newer copy.
